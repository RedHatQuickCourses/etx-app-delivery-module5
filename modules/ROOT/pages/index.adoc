== What's in this course?

In this course, you'll learn how to modernize enterprise Java applications using **Red Hat Migration Toolkit for Applications (MTA)**, **Red Hat Developer Lightspeed**, and **Red Hat OpenShift Dev Spaces**. You'll assess and analyze applications, identify migration requirements, and use AI-assisted recommendations to modernize an application from **JBoss EAP 7 to JBoss EAP 8**.

Duration: 1.5 hours

### Learning Objectives

By the end of this module, you will be able to:

* Explain how MTA supports enterprise application modernization
* Assess and analyze Java applications for migration to JBoss EAP 8
* Identify Java EE to Jakarta EE migration requirements
* Configure MTA with Red Hat MaaS and Developer Lightspeed
* Use the MTA extension in Red Hat OpenShift Dev Spaces
* Apply AI-assisted migration recommendations to modernize applications
* Validate and build a modernized application
