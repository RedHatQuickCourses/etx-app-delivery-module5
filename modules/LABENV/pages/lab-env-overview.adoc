= Lab Environment
:navtitle: Lab Environment

**No new lab environment is required for this module.** Continue using the **same RHDP lab environment** that you provisioned in **https://redhatquickcourses.github.io/etx-app-delivery-module2/etx-app-delivery-module2/1/index.html[_Software Factory Foundations with OpenShift Dev Spaces_, window=browser]**. 

The environment includes the https://catalog.demo.redhat.com/catalog/babylon-catalog-prod?item=babylon-catalog-prod/openshift-cnv.app-platform-factory-cnv.prod&utm_source=webapp&utm_medium=share-link[**Service Enablement: App Platform Software Factory**] and https://catalog.demo.redhat.com/catalog/babylon-catalog-prod?item=babylon-catalog-prod/openshift-cnv.app-platform-runtime-cnv.prod&utm_source=webapp&utm_medium=share-link[**Service Enablement: App Platform Runtime**] labs required for this module.

Do **not** provision, delete, reset, or reprovision the environment. The labs in this module build on the applications, configurations, and platform resources created in **https://redhatquickcourses.github.io/etx-app-delivery-module2/etx-app-delivery-module2/1/index.html[_Software Factory Foundations with OpenShift Dev Spaces_, window=browser]**.

The cluster URLs and credentials are available from the **My Services** page in RHDP.

== Internal Lab Account Credentials

Use the following accounts throughout the learning path.

[cols="1,1,2",options="header"]
|===
|Username |Password |Purpose

|`platform-admin`
|`openshift`
|Platform administrator

|`platform-developer`
|`openshift`
|Application developer

|`platform-user`
|`openshift`
|Standard user
|===

Unless instructed otherwise, authenticate to GitLab, Quay, Vault, and other integrated services using **Keycloak Single Sign-On (SSO)**.

== Platform Services

The following services are pre-configured and available throughout the labs.

[cols="1,2",options="header"]
|===
|Service |Purpose

|Red Hat Build of Keycloak
|Provides centralized authentication and Single Sign-On (SSO).

|GitLab
|Hosts the application source code and Git repositories.

|Red Hat Quay
|Stores container images built during the labs.

|OpenShift GitOps
|Continuously synchronizes applications and platform resources from Git.

|HashiCorp Vault
|Securely stores secrets used by applications and CI/CD pipelines.
|===

All service URLs are available from the **https://demo.redhat.com/[Red Hat Demo Platform (RHDP)] Lab Information** in **My Services** section page.
