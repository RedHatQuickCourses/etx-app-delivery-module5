= Lab 7: Install the MTA Extension in Dev Spaces
:navtitle: Lab 7: Install the MTA Extension in Dev Spaces
:experimental:

In this lab, you'll install and configure the Migration Toolkit for Applications (MTA) extension in your Dev Spaces workspace. You'll prepare the Coolstore application for migration analysis from JBoss EAP 7 to JBoss EAP 8 and enable AI-assisted remediation directly in the IDE.

By the end of this lab, you will have:

* Created a Dev Spaces workspace for the Coolstore application
* Installed the Language Support for Java extension
* Installed the MTA extension
* Connected the MTA extension to the MTA web console
* Created a migration profile for JBoss EAP 7 to JBoss EAP 8

== Install the MTA Extension in Dev Spaces

The Coolstore application needs to be migrated from JBoss EAP 7 to JBoss EAP 8. You'll start by preparing your Dev Spaces workspace and installing the MTA extension to bring migration analysis and AI-assisted remediation directly into the IDE.

=== Access your Dev Spaces workspace

+
[source,role="execute",subs="attributes+"]
----

echo "$GITLAB_URL"
----

== Configure the MTA Extension

Connect the MTA extension to the MTA web console and create a migration profile for the Coolstore application.

. Retrive the OPENSHIFT_CLUSTER_INGRESS_DOMAIN from below command as you will need it in upcoming steps.
+
[source,role="execute",subs="attributes+"]
----
OPENSHIFT_CLUSTER_INGRESS_DOMAIN=$(oc get ingresses.config.openshift.io cluster -o jsonpath='{.spec.domain}')
echo ${OPENSHIFT_CLUSTER_INGRESS_DOMAIN}
----

. Open the Analysis Panel by clicking btn:[Open Analysis Panel]
+
.Analysis Panel(_Click the image to view it in full size in a new browser tab_)
image::mta-analysis-panel.png[align="center"]

. From the top-right corner of the Visual Studio Code window, select the **Settings** option to access the MTA configuration panel.
+
.MTA Settings(_Click the image to view it in full size in a new browser tab_)
image::mta-settings-view.png[align="center"]

. Click btn:[Configure Hub Settings] under *Hub Configuration*
+
.Hub Configuration(_Click the image to view it in full size in a new browser tab_)
image::mta-hub-configure.png[align="center"]
+
In the settings screen, fill in the details, make sure to substitute **OPENSHIFT_CLUSTER_INGRESS_DOMAIN** you retreive from **Step 1**.
+
* **Enable Hub**: Checked
* **Hub URL**: `https://mta-openshift-mta.${OPENSHIFT_CLUSTER_INGRESS_DOMAIN}
* **Insecure connection**: Checked
* **Enable authentication**: Checked
* **Select**: btn:[Credentials]
* **Username**: `platform-admin`
* **Password**: `openshift`
* **Solution Server**: Enabled
* **Profile Sync**: Enabled
+
Click btn:[Save]
+
.Hub Settings(_Click the image to view it in full size in a new browser tab_)
image::hub.png[align="center"]

. Close **MTA Hub Configuration** tab and open the **MTA Analysis Panel** tab.

. Click btn:[Edit in Profile Manager] to create a new profile
+
.Edit in Profile Manager Settings(_Click the image to view it in full size in a new browser tab_)
image::profile.png[align="center", width=500]

. Click btn:[New Profile] 
+
.New Profile(_Click the image to view it in full size in a new browser tab_)
image::profile2.png[align="center", width=500]
+
Fill in the details:
+
* **Profile Name**: `coolstore`
* **Target Technologies**: Select `eap8`
* **Source Technologies**: Select `eap7`
* **Use Default Rules**: Checked
+
.New Profile(_Click the image to view it in full size in a new browser tab_)
image::mta-profile-save.png[align="center"]
