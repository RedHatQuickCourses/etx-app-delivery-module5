**What's in this section?**

In this section, you'll learn how to modernize enterprise Java applications using Red Hat Migration Toolkit for Applications (MTA) and Red Hat Developer Lightspeed.

You'll explore how MTA supports application modernization at scale, assess migration requirements, and analyze the Coolstore application for migration from JBoss EAP 7 to JBoss EAP 8. You'll then use AI-assisted recommendations in Red Hat OpenShift Dev Spaces to identify and apply migration changes and validate the modernized application.
