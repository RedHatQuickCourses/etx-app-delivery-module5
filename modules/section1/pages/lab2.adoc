= Lab 2: Install Migration Toolkit for Applications
:navtitle: Lab 2: Install MTA
:experimental:

In this lab, you'll install the Migration Toolkit for Applications (MTA) Operator from OperatorHub and verify that the installation completes successfully.

By the end of this lab, you will have:

* Installed the Migration Toolkit for Applications Operator
* Verified that the MTA Operator is ready

== Install the Migration Toolkit for Applications Operator

The Migration Toolkit for Applications Operator provides the components required to deploy and manage MTA on OpenShift.

. Open the OpenShift web console.

. Sign in using the `admin` credentials provided on the RHDP Lab Environment page.

. From the navigation menu, select btn:[Ecosystem] -> btn:[Software Catalog].
+
.Ecosystem -> Software Catalog(*Click the image to view it in full size in a new browser tab*)
image::menu.png[link={imagesdir}/menu.png, width=350,window=_blank]

. Search for *Migration Toolkit for Applications* and select the operator. Then, click btn:[Install].
+
.Migration Toolkit for Applications Operator(*Click the image to view it in full size in a new browser tab*)
image::mta2.png[link={imagesdir}/mta2.png, width=350,window=_blank]

. Accept the default installation options and click btn:[Install].
+
.Install Migration Toolkit for Applications Operator(*Click the image to view it in full size in a new browser tab*)
image::install.png[link={imagesdir}/install.png, width=350,window=_blank]

. Wait until the operator reaches the *Succeeded* state.
+
.Installing the MTA Operator(*Click the image to view it in full size in a new browser tab*)
image::mta_install.png[link={imagesdir}/mta_install.png, width=500]
+
[NOTE]
====
Do not create the `Tackle` custom resource during installation. You'll deploy it manually in the next exercise.
====
