= Lab 1: Migration Toolkit for Applications Prerequisites
:navtitle: Lab 1: MTA Prerequisites
:experimental:

In this lab, you'll configure the Red Hat Model-as-a-Service (MaaS) platform and create an API key for AI-assisted application modernization. You'll use this API key in the upcoming Migration Toolkit for Applications (MTA) labs.

By the end of this lab, you will have:

* Accessed the Red Hat MaaS platform
* Subscribed to the required Granite model
* Created and saved an API key for MTA

== Configure the Red Hat MaaS Platform

Migration Toolkit for Applications integrates with Red Hat Developer Lightspeed to provide AI-assisted migration recommendations. Before using MTA, configure the Red Hat Model-as-a-Service (MaaS) platform and create an API key.

. Open the [https://maas-rhdp-frontend.apps.maas.redhatworkshops.io/login/[Red Hat MaaS Portal]] in your browser and sign in using your Red Hat account.
+
.Red Hat MaaS Portal(*Click the image to view it in full size in a new browser tab*)
image::maas.png[link={imagesdir}/maas.png, width=600]

. From the navigation menu, select **Models**.
+
.Red Hat MaaS Portal Home page(*Click the image to view it in full size in a new browser tab*)
image::models.png[link={imagesdir}/models.png, width=600]

. Select **granite-3-2-8b-instruct** and click btn:[Subscribe].
+
.Subscribe to Granite model(*Click the image to view it in full size in a new browser tab*)
image::subscribe.png[link={imagesdir}/subscribe.png, width=600]

. From the navigation menu, select **API Keys**.
+
.Red Hat MaaS API Keys(*Click the image to view it in full size in a new browser tab*)
image::api.png[link={imagesdir}/api.png, width=600]

. Click btn:[Create API Key].
+
.Create API Key(*Click the image to view it in full size in a new browser tab*)
image::key.png[link={imagesdir}/key.png, width=600]

. Enter the following values and click btn:[Create API Key]:

* *Name*: `MTA-Dev`
* *Description*: `AI-assisted modernization for MTA`
* *Model*: `granite-3-2-8b-instruct`

. Copy the generated API key and save it securely. You'll use this key in the upcoming MTA labs.
