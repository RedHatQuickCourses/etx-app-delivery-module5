Lab 1: Migration Toolkit for Applications Prerequisites

In this lab, you’ll configure the Red Hat Model-as-a-Service (MaaS) platform and create an API key for AI-assisted application modernization. You’ll use this API key in the upcoming Migration Toolkit for Applications (MTA) labs.

By the end of this lab, you will have:

  • Accessed the Red Hat MaaS platform

  • Subscribed to the required Granite model

  • Created and saved an API key for MTA

Configure the Red Hat MaaS Platform

Migration Toolkit for Applications integrates with Red Hat Developer Lightspeed to provide AI-assisted migration recommendations. Before using MTA, configure the Red Hat Model-as-a-Service (MaaS) platform and create an API key.

  1. Open the [Red Hat MaaS Portal] in your browser and sign in using your Red Hat account.

    Figure 1. Red Hat MaaS Portal(Click the image to view it in full size in a new browser tab)

  2. From the navigation menu, select Models.

    Figure 2. Red Hat MaaS Portal Home page(Click the image to view it in full size in a new browser tab)

  3. Select granite-3-2-8b-instruct and click Subscribe.

    Figure 3. Subscribe to Granite model(Click the image to view it in full size in a new browser tab)

  4. From the navigation menu, select API Keys.

    Figure 4. Red Hat MaaS API Keys(Click the image to view it in full size in a new browser tab)

  5. Click Create API Key.

    Figure 5. Create API Key(Click the image to view it in full size in a new browser tab)

  6. Enter the following values and click Create API Key:

    • Name: MTA-Dev

    • Description: AI-assisted modernization for MTA

    • Model: granite-3-2-8b-instruct

  7. Copy the generated API key and save it securely. You’ll use this key in the upcoming MTA labs.

    Figure 6. Sample API Key Information(Click the image to view it in full size in a new browser tab)
