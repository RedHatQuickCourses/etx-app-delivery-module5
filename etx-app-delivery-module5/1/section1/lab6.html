Lab 6: Analyze the Coolstore Application

In this lab, you’ll analyze the Coolstore application with Migration Toolkit for Applications (MTA), targeting JBoss EAP 8. You’ll review the migration findings and identify the changes required to modernize the application.

By the end of this lab, you will have:

  • Analyzed the Coolstore application for JBoss EAP 8

  • Reviewed the generated migration report

  • Identified issues requiring migration changes

  • Understood the javax to jakarta migration requirements

Analyze the Application

Run an application analysis targeting JBoss EAP 8.

  1. Select the coolstore application.

  2. Click Analyze.

    Figure 1. Start Analysis(Click the image to view it in full size in a new browser tab)

  3. Configure the analysis using the following options:

    Mode: Manual Selection Target Runtime: JBoss EAP 8 Scope: Application and internal dependencies only

    Figure 2. Mode settings(Click the image to view it in full size in a new browser tab)
    Figure 3. Analysis settings(Click the image to view it in full size in a new browser tab)
    Figure 4. Set targets settings(Click the image to view it in full size in a new browser tab)
    Figure 5. Scope settings(Click the image to view it in full size in a new browser tab)

  4. Accept the remaining defaults and click Run.

    Figure 6. Review Analysis details(Click the image to view it in full size in a new browser tab)

The analysis scans the application’s source code, dependencies, and configuration files using the built-in MTA migration rules.

  1. Wait for the analysis to complete.

    Figure 7. Analysis Complete(Click the image to view it in full size in a new browser tab)

Review the Analysis Report

Once the analysis completes, review the migration findings.

  1. Open the coolstore application.

  2. Select the Issues tab.

    Figure 8. Analysis Report(Click the image to view it in full size in a new browser tab)

  3. Review the reported issues:

    • Mandatory — Changes required for the migration to succeed.

    • Potential — Recommended improvements.

    • Information — Additional guidance and documentation.

Figure 9. Migration Issue Categories(Click the image to view it in full size in a new browser tab)
The migration report identifies code changes required to migrate the application from Java EE (javax) to Jakarta EE (jakarta). In the next lab, you’ll use Red Hat Developer Lightspeed to generate AI-assisted recommendations for addressing these issues.
