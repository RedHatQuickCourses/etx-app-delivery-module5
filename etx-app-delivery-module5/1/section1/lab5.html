Lab 5: Import the Coolstore Application

In this lab, you’ll add the Coolstore application to the Migration Toolkit for Applications (MTA) Application Inventory and configure its GitLab source repository for analysis.

By the end of this lab, you will have:

  • Created a Coolstore application entry in MTA

  • Connected the application to its GitLab source repository

  • Configured the application branch and runtime tag

Import the Coolstore Application

Create an application entry for the Coolstore application in the MTA Application Inventory.

  1. In the MTA web console, navigate to Migration → Application Inventory → Create new.

    Figure 1. Application Inventory(Click the image to view it in full size in a new browser tab)

  2. Enter the following values and click Create.

    • Name: coolstore

    • Manual Tags: Runtime/EAP

    • Source Repository: {gitlab_url}/mta-apps/coolstore.git

    • Branch: main
