Lab Summary

In this section, you prepared and used Migration Toolkit for Applications (MTA) to assess the Coolstore application for migration from JBoss EAP 7 to JBoss EAP 8.

You started by configuring the Red Hat Model-as-a-Service (MaaS) platform and creating an API key to enable AI-assisted application modernization. You then installed the MTA Operator and deployed the MTA web console with Developer Lightspeed integration.

Next, you configured GitLab access in MTA and added the Coolstore application to the MTA Application Inventory. You performed an application analysis targeting JBoss EAP 8 and reviewed the generated migration report to identify compatibility issues and required migration changes.

By completing this section, you have:

  • Configured Red Hat MaaS for AI-assisted modernization

  • Installed and deployed Migration Toolkit for Applications

  • Configured GitLab access for application source code

  • Added the Coolstore application to the MTA Application Inventory

  • Analyzed the application for migration to JBoss EAP 8

  • Reviewed migration findings and identified required changes

  • Understood the Java EE (javax) to Jakarta EE (jakarta) migration requirements

The next section builds on this foundation by using Red Hat OpenShift Dev Spaces and the MTA extension to perform AI-assisted analysis and apply migration recommendations directly in the development environment.
