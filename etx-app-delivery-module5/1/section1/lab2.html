Lab 2: Install Migration Toolkit for Applications

In this lab, you’ll install the Migration Toolkit for Applications (MTA) Operator from OperatorHub and verify that the installation completes successfully.

By the end of this lab, you will have:

  • Installed the Migration Toolkit for Applications Operator

  • Verified that the MTA Operator is ready

Install the Migration Toolkit for Applications Operator

The Migration Toolkit for Applications Operator provides the components required to deploy and manage MTA on OpenShift.

  1. Open the OpenShift web console.

  2. Sign in using the admin credentials provided on the RHDP Lab Environment page.

  3. From the navigation menu, select Ecosystem → Software Catalog.

    Figure 1. Ecosystem → Software Catalog(Click the image to view it in full size in a new browser tab)

  4. Search for Migration Toolkit for Applications and select the operator. Then, click Install.

    Figure 2. Migration Toolkit for Applications Operator(Click the image to view it in full size in a new browser tab)

  5. Accept the default installation options and click Install.

    Figure 3. Install Migration Toolkit for Applications Operator(Click the image to view it in full size in a new browser tab)

  6. Wait until the operator reaches the Succeeded state.

    Figure 4. Installing the MTA Operator(Click the image to view it in full size in a new browser tab)

    Do not create the Tackle custom resource during installation. You’ll deploy it manually in the next exercise.

Verify the Installation

Verify that the MTA Operator is installed successfully.

oc get csv -n openshift-mta
