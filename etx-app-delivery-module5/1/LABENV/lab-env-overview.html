Lab Environment

Before starting the hands-on exercises, provision the required lab environments from the Red Hat Demo Platform (RHDP).

This learning path uses two OpenShift clusters that represent different stages of a software delivery pipeline. Both environments should be provisioned before you begin the labs.

  • RHDP for RedHat associates: https://demo.redhat.com/

  • RHDP for RedHat partners: https://partner.demo.redhat.com/

Lab Environments

No new lab environment is required for this module. Continue using the same RHDP lab environment that you provisioned in Software Factory Foundations with OpenShift Dev Spaces.

The environment includes the Service Enablement: App Platform Software Factory and Service Enablement: App Platform Runtime labs required for this module.

Do not provision, delete, reset, or reprovision the environment. The labs in this module build on the applications, configurations, and platform resources created in Software Factory Foundations with OpenShift Dev Spaces.

The cluster URLs and credentials are available from the My Services page in RHDP.

OpenShift Clusters

Environment Purpose Used In

Service Enablement: App Platform Software Factory (Primary Cluster)

Development platform where you’ll build the internal developer platform, configure CI/CD, and deploy applications.

  • Software Factory Foundations with OpenShift Dev Spaces

  • Software Delivery with OpenShift Pipelines and GitOps

  • DevEx with Red Hat Developer Hub

  • Application Modernization with MTA

Service Enablement: App Platform Runtime (Secondary Cluster)

Runtime environment used to demonstrate GitOps-based promotion between environments.

  • Software Delivery with OpenShift Pipelines and GitOps

The required namespaces have already been created and are ready for use.

Platform Services

The following services are pre-configured and available throughout the labs.

Service Purpose

Provides centralized authentication and Single Sign-On (SSO).

GitLab

Hosts the application source code and Git repositories.

Red Hat Quay

Stores container images built during the labs.

OpenShift GitOps

Continuously synchronizes applications and platform resources from Git.

HashiCorp Vault

Securely stores secrets used by applications and CI/CD pipelines.

All service URLs are available from the Red Hat Demo Platform (RHDP) Lab Information in My Services section page.
